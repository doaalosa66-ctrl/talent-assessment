# 路之音智能人才评估与面试决策系统

一个基于AI的智能人才评估系统,通过DeepSeek大模型深度分析岗位需求和候选人简历,提供全面的评估报告和面试决策建议。

## 核心功能

### 输入（极简设计）
- **输入框1**: 公司背景 + 岗位JD要求
- **输入框2**: 上传候选人简历（支持批量上传PDF/Word/TXT）

### 输出（5大维度深度分析）

#### 1. 岗位能力分析报告
- 核心能力维度提取
- 各能力维度权重分配
- 岗位胜任力模型可视化
- 关键硬性要求（一票否决项）

#### 2. 候选人综合评估看板
- 能力雷达图对比
- 匹配度评分表（技术/经验/文化/综合评分）
- 推荐等级一目了然

#### 3. 候选人深度分析档案
针对每位候选人:
- ✅ 核心优势分析（3-5个关键优势点）
- ⚠️ 潜在风险与短板识别
- 📉 与岗位要求的gap分析
- 📈 成长潜力评估
- 🤝 团队融合度预测

#### 4. 智能邀约决策报告
- 邀约建议：强烈推荐/推荐/待定/不推荐
- 决策理由分析（基于量化数据）
- 预期面试通过率预测
- 薪资期望匹配度分析

#### 5. 深度测评与面试方案
为推荐候选人定制:
- 技术深度测评题（3-5道，针对技术短板）
- 行为面试题（2-3道，考察软技能）
- 情景模拟题（1-2道，基于实际场景）
- 每道题包含：参考答案、评分标准、考察维度、红牌警告信号

## 技术架构

### 后端
- **框架**: Node.js + Express
- **AI引擎**: DeepSeek API (通过OpenAI SDK集成)
- **简历解析**: pdf-parse + mammoth (支持PDF和Word)
- **文件上传**: multer

### 前端
- **框架**: React 18 + Vite
- **UI组件**: Ant Design 5
- **数据可视化**: Recharts（雷达图）
- **HTTP客户端**: Axios

## 使用指南

### 第一步: 输入岗位信息
在"输入框1"中填写:
- 公司背景（业务领域、发展阶段、团队文化、技术栈等）
- 岗位JD（岗位职责和任职要求）

### 第二步: 上传候选人简历
在"输入框2"中:
- 点击上传区域或拖拽文件
- 支持PDF、Word、TXT格式
- 支持批量上传（最多20份）

### 第三步: 开始评估
点击"开始智能评估"按钮,系统将:
1. 深度分析岗位JD
2. 解析所有候选人简历
3. 进行多维度评估
4. 生成邀约决策
5. 为推荐候选人生成测评方案

### 第四步: 查看报告
系统输出3个Tab页面:
- **岗位能力分析**: 查看岗位能力模型
- **候选人对比看板**: 横向对比所有候选人
- **候选人详细分析**: 每个候选人的完整评估档案

## 评估维度说明

系统从以下维度评估候选人:

| 维度 | 权重 | 说明 |
|------|------|------|
| 技术匹配度 | 30% | 技术栈、编程能力、架构设计 |
| 经验匹配度 | 25% | 项目规模、行业经验、技术难度 |
| 文化契合度 | 20% | 工作风格、团队协作倾向 |
| 成长潜力 | 15% | 学习能力、技术演进轨迹 |
| 职业稳定性 | 10% | 工作连续性、跳槽频率 |

## 推荐等级判定

- **综合评分 > 85**: 强烈推荐 ⭐⭐⭐
- **综合评分 70-85**: 推荐 ⭐⭐
- **综合评分 60-70**: 待定 ⭐
- **综合评分 < 60**: 不推荐

## 常见问题

### Q: 简历上传失败?
A: 请确保文件格式为PDF、Word或TXT,且单个文件不超过10MB

### Q: 评估速度慢?
A: 系统需要调用AI进行深度分析,处理时间取决于:
- 候选人数量（每个候选人需要多次AI调用）
- 简历复杂度
- 网络状况

建议首次测试使用1-2份简历

### Q: 如何理解评分?
A: 系统采用0-100分制,综合考虑多个维度,并非单一技能匹配
